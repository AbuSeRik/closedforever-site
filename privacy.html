Privacy policy

Last updated: October 1, 2026

This policy covers the Closed Forever uploader, a private tool that uploads videos to the Closed Forever YouTube channel.

What the tool accesses

When the channel owner signs in with Google, the tool receives permission to upload videos, set thumbnails and read the status of videos on that one channel. It uses the YouTube Data API for this.

What the tool stores

The tool stores one Google sign-in token on the owner's own server so it can upload videos on schedule. It does not store any other Google account data.

What the tool does not do

The tool does not collect data about viewers or other people. It does not sell or share data with anyone, and it does not use data for advertising.

Google API Services

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used under the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can remove the tool's access at any time on the Google Account permissions page. The stored token then stops working.
